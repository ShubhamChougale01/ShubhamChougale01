### 🎙️ AI Assistant — Voice-First Personal Assistant
> A full-stack, production-grade voice assistant that lets you manage tasks, reminders, and calendar events by speaking. Built with FastAPI, React 18, Deepgram STT/TTS, and Groq LLM for sub-50ms intent parsing.

| | |
|--|--|
| **Backend** | FastAPI · PostgreSQL · SQLAlchemy 2.0 async · Alembic · APScheduler · WebSocket · JWT |
| **Frontend** | React 18 · TypeScript · Vite · TanStack Query · shadcn/ui · Tailwind CSS |
| **Voice & AI** | Deepgram STT/TTS · Groq (Llama 3.3) · Multi-turn clarification · MCP tool registry |

**How it works:**
```
You speak → Deepgram transcribes → Groq parses intent → Action executed → TTS response plays
                                  ↓ confidence < 0.7
                            Multi-turn clarification loop
```

**What you can say:**
- *"Remind me to call the client at 3pm"*
- *"Add a task: finish the report by Friday"*
- *"Schedule a meeting tomorrow at 10"*
